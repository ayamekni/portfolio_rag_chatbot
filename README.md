# 💫 Aya Portfolio Chatbot

An interactive AI assistant built with **Next.js** and **TypeScript**, designed to answer questions about your professional experience, skills, and projects — directly from your résumé.  
It features a modern floating chat widget and a lightweight local retrieval system for fast, private responses.

---

## 🚀 Features

- 🧠 **AI Chat Interface** — Responds to questions about your CV and portfolio content.
- 💬 **Floating Chat Widget** — Seamlessly integrated, modern, animated, and mobile-responsive.
- ⚡ **Local Retrieval** — Retrieves context from your CV without relying on external APIs.
- 🎨 **Customizable UI** — Elegant glass-morphism interface matching your portfolio theme.
- 🔒 **Private by Design** — Your data stays local; no personal files or API keys are exposed.
